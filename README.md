# Virtualizor 授权验证与本地更新服务说明

本项目通过搭建独立服务节点，实现对 Virtualizor 授权验证的本地化管理，并直接托管与分发版本元数据及更新安装包，确保主控端在脱离官方网络依赖的情况下仍能稳定运行与版本升级。

---

## 架构工作原理

服务节点通过接管 `api.virtualizor.com` 域名，实现授权校验与版本更新的全面本地化处理：

* **授权验证服务 (`license2.php`)**：响应主控端的授权查询请求，返回本地生成的授权凭证，完成环境激活与功能解锁。
* **版本更新与分发服务 (`updates.php`)**：替代原有的官方透传机制，直接由本地服务解析版本请求、返回最新版本元数据，并分发本地存储的更新安装包（`.pkg`）。

---

## 工具脚本说明

服务端提供两套核心数据处理脚本，用于管理与维护授权凭证：

* **`encode.php`（授权加密）**：将自定义的 JSON 格式授权元数据（如到期时间、虚拟化架构支持、IP 限制、授权类型等）编译加密，生成 `license2.php` 所需的数据密文。
* **`decode.php`（授权解密）**：用于逆向解析 `license2.php` 中的加密内容，还原并格式化输出 JSON 明文，便于校验与配置审计。
